# 抖音广告任务中间商研究与落地资料

研究日期：2026-10-14（中国时间）；项目ZJS-XM-001，最新版本V1.2。

**本轮补充16个平台或音乐上游条目，累计88条来源记录、23个机构/目录线索。已准备合作核验和首单材料；尚无本项目渠道授权、客户订单、达人同意或实际收入。** 机构线索数不等于独立预算来源数。

## 本轮优先阅读

- [其他平台与渠道合作比较](research/06_其他平台与渠道合作比较.md)：WEIQ、右豹、橙星推、抖推猫/创作猫、螃蟹和红人通告、U客及音乐上游。
- [其他平台合作询问包](ops/其他平台合作询问包.md)：角色、费用、分佣、归因、退出、结算的接洽草稿与招募模板；未发送。
- [其他平台核验数据](data/其他平台核验.json)：16条核验记录，佣金、实际费用和本项目许可保留未知。
- [V1.2变更与未决事项](project/V1.2_其他平台研究与未决事项.md)。

研究判断：团队模式优先确认右豹、橙星推和抖推猫的正式合作条件；品牌执行模式查看WEIQ；博主招募可考察螃蟹、红人通告；音乐主线仍优先核验星斗推联盟，并补粤兔与米喜产业线索。不是“加好友或买会员后天然抽佣”。
