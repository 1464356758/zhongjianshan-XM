# 上游渠道核验与首单判断

版本：V1.1。核验日期：2026-10-14（中国时间）。本轮承接V1.0，重点回答“究竟在哪条链路里获得自己的报酬”。

**优先候选是星斗推营销联盟；目前只核实公开存在分佣介绍，尚未取得本项目入驻、佣金比例、任务授权或回款证据。备选是新榜有赚的达人资源合作。公开任务转发本身不产生佣金权。**

## 1. 本轮新增的关键证据

### 官方音乐任务：达人不能领完再转给别人做

汽水音乐合作平台2026年6月协议明确禁止宣推达人接任务后再转委托或安排第三方实际提供服务。接单账号与实际执行不能用中间商身份混淆。协议定义了达人自选的特约服务提供商，但这个定义涉及管理及结算等服务，并不授予任何个人招募下级、接单转包或代收所有达人款的资格。[S15]

因此，需由实际达人按允许链路接单、执行；你的角色和报酬另有正式依据。第三方平台自称接入开放平台，证明的是其公开介绍，不代表全部订单都获得星图广告交易许可。[S03][S18]

### 星斗推：找到明确的联盟分佣介绍

应用宝公开产品简介说明：营销联盟面向有优质达人资源、提供运营和商务服务的个人或企业，具备成员管理、任务发布及旗下达人接单分佣功能。这是运营方的产品自述，不是本项目已获准入。海葵官网进一步描述盟主协助接单与成员管理。[S50][S20]

应用宝列武汉网海科技有限公司为开发者、武汉航海图科技有限公司为运营者；iOS商店列北京海葵科技有限公司。星斗推官网隐私政策列武汉航海图为主要运营公司，并说明与北京海葵的关联关系。不同商店字段不能直接推断为假平台，也不能跳过最终合同、收款及开票主体核验。[S50][S18][S51]

**仍未公开核实：**是否接受筹备中的小团队；最少成员数；有无入驻费、保证金或预存款；音乐任务是否全部计佣；佣金基数与比例；达人绑定冲突与退出；对账、提现、税务和申诉期限。营销联盟名称不等于这些条件已经满足。

### 新榜：三个产品身份要分开

新榜有赚资源合作页支持抖音等平台，表单区分公司/个人，征集资源及合作方式。它是资源合作入口，未公开保证给资源中间人固定比例。[S27]

新榜官方合伙人招募页另有代理产品和自动结算宣传，搜索摘要显示“小豆芽预存费10000元”。本轮正文访问不稳定，不能把这项费用扩展为所有资源合作或广告推荐的统一门槛，也不能把产品代理证书当作你的星图代理资格。[S52]

新榜历史推广人文章曾规定：推荐绑定公众号，按激活、首单及后续订单结算计奖，订单分佣2%、期限6个月。**原文写活动截止2023年9月30日。它不是2026年可直接参加的抖音音乐渠道。**这里只保留为“正式归因应怎样写清楚”的历史案例，不纳入现行收入测算。[S53]

### 微播易：资源合作与交易担保是两回事

微播易有自媒体变现合作入口及公共客服邮箱；公开免责声明说明其是第三方交易平台、部分核实仅供参考，广告发布争议由交易双方解决。不能因为通过平台就认为全部报价、效果或付款已得到担保。[S54][S55]

## 3. 任务值不值得组织：先过条件，再算钱

以下是本项目经营验收标准，不是平台统一规则。条件未知就暂停发布，不将“未知”当成默认允许。

| 必须明确的条件 | 能通过的证据 | 不能通过的情况 |
| --- | --- | --- |
| 主体与付款方 | 正式主体、签约权限、合同与付款/开票关系 | 只给陌生人的收款码 |
| 你的角色 | 允许的联盟、推荐或执行范围；平台所需批准已满足 | 达人账号接完再转给别人；借号操作 |
| 你的报酬 | 本项目具体费用、基数、比例/固定价与付款方 | 只有公共任务链接或口头“以后分成” |
| 归因 | 成员及任务绑定成功记录；冲突、解除、在途订单规则 | 只用微信群人数或转发截图认佣 |
| 真实订单 | 有效任务ID、版本、报名/选中状态及预算规则 | 过期海报、过期活动、无可承接任务 |
| 内容与权利 | 音源ID、使用场景、素材许可、可执行标准 | 只有歌名；让达人搬运无授权素材 |
| 验收与结算 | 指标来源、审核/复核、封顶、冻结日、支付起算日 | “点赞越多越赚”但无封顶和付款说明 |
| 资金与劳动 | 保守成本及工时能承担；达人付款责任明确 | 用达人应付款垫自己的运转，或亏损还扩池 |

结算数据可见不等于可提现；可提现不等于已经到账。一次真实回款只证明该笔合作，不证明长期供给或每首歌都赚钱。

## 4. 四种常见回复，如何判定

| 对方的回复 | 判断 | 已准备的后续核验 |
| --- | --- | --- |
| “任何人都可接，链接给你” | 没证明你的佣金权 | 询问是否有独立渠道ID和可对账收入 |
| “拉进群，先付培训/会员费” | 先核收费服务及独立价值，不按任务授权处理 | 对照主体、协议、退款、任务和佣金；不先付款 |
| “可以进联盟，比例后台看” | 有机会，尚不能向达人报价 | 要当前规则、绑定机制及一笔脱敏完整结算演示 |
| “每个合格账号/作品给固定执行费” | 可谈明确交付，有机会摆脱效果薄佣 | 核平台许可、验收范围、失败/修改成本与正式付款 |

不要因对方说“供应商”“合作伙伴”就自动通过。实际职责涉及被禁止的下级服务商或私单时，名称无效。[S03]

## 5. 对赚钱规模的修正判断

纯转发的信息差容易被平台搜索、比价和达人直接报名削弱。建议把收费对象转为可验收的工作：权限及档期确认、内容匹配、执行管理、修改反馈和结案。是否有人愿意付费仍待验证。

首批音乐任务用于查清链路和操作成本；若每条佣金覆盖不了找人及返工，就不扩人数。品牌执行服务可能有更高的单笔报酬，但需要真实销售与交付能力。两条业务分别记录成本、客户和归因，不能用一个爆款的收益抵消所有失败而不记录。

新增的首单模型在原V1.0基础上计入招募现金成本和经营者工时；所有数值仍是经营假设。新增文件给出已经计算完的结果，不要求现在注册或使用任何平台。

## 6. 当前完成程度

完成：优先渠道的公共证据链、首轮接洽稿、合作确认附件、任务发布前核验表、两条获客流程、首单报价和停止条件。

未完成：平台对本项目的入驻决定、任务或渠道授权、已同意的真实达人、客户订单、实际交付、提现及回款。不能从公开页面推导这些结果，也没有用虚构主体或登录绕开这一缺口。

本轮结论是“已有更具体的可谈入口，首单资料已备齐”，商业状态仍为未验证。
