# 抖音广告任务中间商：规则、音乐任务与落地方案
研究日期：2026年10月14日（中国时间）｜项目：ZJS-XM-001｜版本：V1.0

## 01 判断：可以经营，但需要拿到真实授权和预算

你的想法有现实业务对应：聚合有创作能力的博主，替有预算的机构做筛选、邀约、内容执行与对账，再收取合同约定的报酬。巨量星图明确存在任务服务商、撮合服务商和代理商等角色；这些角色提供的服务与你设想的中间商业务重合。[S03][S06]

当前值得尝试的定位是“细分达人招募与任务执行服务”。先用一个小任务证明你能交付，再争取重复预算。音乐任务适合试验匹配、投稿和结算，但单条薄佣金不宜直接当作赚大钱的依据。

这次研究得出的结论有三个层次：

| 判断层次 | 结论 | 本次证据 |
| --- | --- | --- |
| 市场里是否有这种生意 | 有 | 官方定义、服务商机制、音乐机构与第三方平台业务介绍 |
| 你能否低成本进入 | 有条件 | 第三方联盟或已有机构的经允许合作，须确认身份、权限、计佣和付款 |
| 能否保证赚大钱 | 不能证明 | 尚无你自己的授权订单、试单回款、复购、真实执行成本 |

本次完成公开规则研究、平台和机构入口核查、经营测算、合同要点、30天试单设计。未登录你的账号，未添加任何联系人，未取得任务代理权，未支付任何费用，未产生收入。所有经营单价、佣金和转化率假设均有明确标注。

### 建议采用的两条业务线

第一条：向已有音乐宣推机构或具备渠道功能的平台，核实“允许招募达人且给你渠道计佣”的合作。由达人本人按规定承接、发布，平台按约结算。你负责匹配、指引和跟进，收益通过平台渠道功能或经允许的独立服务合同确认。

第二条：向已有广告机构提供一个细分类目的达人名单与执行服务，再逐步服务有持续投放预算的品牌。业务重心包括筛选、排期、脚本检查、修改反馈、发布核验和结案。能否外包、怎样收费，以及能否另签服务协议，必须与平台规则、主合同一致；不能借外包名义成为未经允许的下级服务商。

暂不建议一开始申请官方代理、自己做音乐任务小程序、垫大额达人款或买大量微信名单。下面的准入和利润章节说明为什么这些动作不能解决当前最先缺少的授权、订单与回款问题。

## 02 广告生态：先确认任务是哪一种

“抖音广告”不是一个统一的任务池。收费指标、资质、后台和结算方式不同，不能把一种模式的门槛与另一种模式的佣金拼在一起使用。

| 类别 | 买方购买什么 | 主要入口 | 中间商可提供什么 |
| --- | --- | --- | --- |
| 品牌指派商单 | 指定博主的定制内容和发布 | 巨量星图 | 选号、询价、排期、内容管理、结案 |
| 招募/达人团 | 批量中小达人内容 | 巨量星图 | 批量筛选与履约，需对应权限 |
| 投稿任务 | 符合要求的内容及传播/转化 | 巨量星图任务体系 | 合规邀约与创作支持，佣金须另有依据 |
| 音乐宣推 | 指定歌曲的传播与内容 | 汽水音乐合作平台、音乐机构、第三方 | 曲目与达人匹配、授权渠道推广、执行 |
| 电商带货 | 商品销售、视频或直播素材 | 巨量百应等 | 选品、达人撮合、素材/运营；看退货退款后佣金 |
| 生活服务 | 到店、团购、探店内容 | 抖音生活服务相关体系 | 本地达人排期、到店与核销跟踪 |
| 游戏/小程序 | 激活、付费、广告收入等 | 抖音开放平台、星图 | 经授权的达人推广与任务管理 |
| 信息流投放 | 广告展示、点击或转化 | 巨量引擎、千川、本地推等 | 素材、投放与优化；是另一套业务 |
| 平台创作激励 | 平台对创作的激励 | 各计划自身入口 | 不能自动转化成你可代理的广告任务 |

官方开放平台的小游戏任务确有指定达人、指定服务商及多种效果结算，但只证明该产品的能力，不能据此推断所有音乐任务也可自由转包。[S47] 百应机构服务商需要其自身的资质审核和协议，不等于取得了星图代理资格。[S49]

必须拆开的四个数字是：客户总预算、达人报酬、你的服务收入、你的经营利润。客户投入10万元，绝不等于你收入10万元；达人拿到100元，也不意味着其中有20元自动属于你。

## 03 官方发布任务与接任务规则

### 3.1 发布任务的主体与资金

星图新客户手册列出的准备流程包括企业资质、对公验证、CA认证、品牌创建和账户预充值。手册目前写明客户账号不支持个体工商户营业执照；这条只针对该客户账号准入，不能扩展为所有广告服务都禁止个体主体。[S01]

发单前至少明确：任务类型、品牌及产品、硬性要求、创作建议、达人范围、报名与交付期限、发布及保留时间、样品或实地条件、营销授权、预算和结算规则。品牌资质、样品、音乐与画面版权不能通过“我只是中间商”省略。

客户、达人和中间商的账号须各自归属正确主体。使用平台提供的协作权限；若无相应权限，由机构自己的授权员工操作。不能拿一套账号密码交给多方轮流使用。

### 3.2 不同任务的公开费用和起投条件

| 任务 | 客户侧公开平台费 | 已查到的其他条件 | 注意 |
| --- | --- | --- | --- |
| 指派一口价 | 5% | 指定达人履约 | 按任务页核对计费基数 |
| 投稿 | 10% | 短视频任务公开说明最低预算池1万元 | 传播效果分配不等于固定单位收益 |
| 招募一口价 | 5% | 任务说明1万元起、自助报价区间最低300元 | 不把其他产品的小额任务套用在这里 |
| 星广联投 | 结算规则称客户费限时免收 | 对应服务商、投流与计费机制 | 临时优惠应在下单时再核查 |

费率来源为结算管理规则，任务门槛来源为相应任务说明。平台费、达人侧扣费、税费以及你自己的合同收费分别核算；不能将所有项目一概称作“平台抽10%”。[S04][S11][S12]

个体达人结算说明列出5%的信息技术管理服务费；绑定MCN的达人经机构结算。该页面也提示，2026年9月20日起符合规则的自然人任务收益自动打款到实名人账户。自动打款和税务扣缴会影响“我替所有达人提现后扣佣”的设想。[S05]

### 3.3 达人接任务没有统一粉丝门槛

| 权限/任务 | 新达人手册公开要求 | 是否还需其他条件 |
| --- | --- | --- |
| 星图入驻 | 入驻本身无粉丝要求 | 内容、账号状态等 |
| 短视频指派 | 10万粉、有效粉丝≥500 | 开通权限并报价 |
| 短视频投稿 | 1万粉、有效粉丝≥500 | 还看任务圈选和要求 |
| 图文一口价/投稿 | 1000粉、有效粉丝≥500 | 还看具体权限 |
| 常规招募 | 手册列1万至500万粉、有效粉丝≥500 | 与单项招募说明有差异 |
| 直播相关 | 部分类型1000粉、有效粉丝≥200 | 部分还要求近期直播与无违规 |

这些是2026年9月22日的新达人手册说明，不代表满足粉丝数就必有订单。[S02]

发现了一处必须保留的规则差异：8月27日招募一口价说明写1K至500W粉；8月23日效果招募说明写1000至5000W粉；9月22日综合手册的常规招募行写1W至500W粉。不能擅自给出一个覆盖所有招募模式的数字。[S08][S12]

实务上将1000至9999粉账号列为“具体任务权限待验证”；若做万粉以上常规招募也要检查账号后台。音乐任务有自己的圈选和接单权限，不能仅以历史教程的“0粉可做”招募所有人。

### 3.4 下单与接单的履约区别

指派一口价是明确对象的订单。完成脚本、视频、发布、验收各环节；内容要按流程确认，发布后未手动验收时该任务说明有七天自动验收规则。它是验收机制，不是任何商单七天无条件到账。[S10]

投稿任务通常是参与内容竞争或效果结算。报名、拍了视频、通过初审、获奖和拿到钱是不同状态。招募任务还需要被选中下单；不应把报名截图当作已有付款义务。

应把“固定稿酬”“保底”“效果奖励”“预算池奖励”写在不同字段。未被选中不能承诺固定稿酬；某些保底也有有效结算指标条件；退款、下架、重复投稿、无效数据和结果公示均可能改变金额。

## 04 你的中间商角色：允许做什么，不能自动做什么

| 做法 | 判断 | 必须具备的证据 |
| --- | --- | --- |
| 转发官方公开邀请，达人自行报名 | 可作为信息服务 | 遵循任务要求；不得谎称已代理或保证收入 |
| 你拿渠道邀请链接，系统归因后分佣 | 有条件可做 | 联盟/渠道协议、计佣规则、结算后台、有效绑定 |
| 给已有机构筛选和管理达人 | 有条件可做 | 明确允许的外包范围、平台要求、服务合同 |
| 你以达人身份接任务，再让别人实际执行 | 音乐宣推现行协议明确禁止 | 不采用；其他业务另核正式规则，不冒充实际执行账号 [S15] |
| 原价复制平台任务，自己换个低价发群抽差额 | 不能据此成立 | 需有合法分发权和完整报酬约定，不能绕订单 |
| 你代领达人收入，再扣“介绍费” | 不应默认采用 | 机构结算资格、达人约定与平台支持；不能挪用应付报酬 |
| 收双方费用而隐瞒身份和计费 | 不采用 | 真实披露委托关系与费用，避免利益冲突 |
| 借“供应商”名称发展被禁止的下级服务商 | 不采用 | 改名字不会改变实际业务认定 |

星图新达人手册禁止私下接单；指派任务说明也禁止线下交易和私下加价。商务微信沟通可以是前期建联，但不能由此把本应在平台中的任务和支付移出平台。[S02][S10]

星图服务商规范要求如实说明被授权范围，且未经星图书面许可不得私自发展下级服务商。“我只与正规机构签一份合同”本身并不能消除这项限制。合作机构应确认你的职责是否涉及下级服务商、需何种批准；不能仅由双方口头同意绕过平台。[S03]

民法典中介合同规范支持有约定、如实报告、满足促成条件的报酬；对绕开中介的同一交易也有相应规定。维权需要证明服务、引入对象、交易与约定报酬的联系，不能把加了好友当作永久佣金权。[S40]

### 4.1 三种适合先谈的收费结构

一、由上游机构购买你明确交付的筛选和执行服务：例如约定一批合格候选、预约确认、内容审核跟进及结案。服务费由上游支付，达人报酬仍按正式任务结算。前提是该外包与收费得到允许。

二、平台确有渠道分佣时，使用其正式归因与结算能力。让达人看到自己的任务规则和最终收益，自己的渠道收益单独记录。邀请码、会员推荐奖励、公会培训权益不能直接当作长期任务佣金。

三、对自有来源且允许的客户，按预算或交付规模约定策划执行服务费。客户直接向正确的平台或履约主体付款。你不冒充官方代理，也不额外向达人收取与平台订单冲突的费用。

这三种是可谈的合同结构，不是本次已获平台认可的权限。若平台不允许某条链路，停止该链路；不能以“独立咨询费”“管理费”名义收取被禁止的私单报酬。

### 4.2 首单建议

从一个明确允许外部执行的任务开始，限定10至20个实际愿意合作的达人。选择内容要求清晰、授权材料齐全、结算能追溯的任务。先谈具体交付，再谈价格。

对上游可提出“候选筛选+发布跟进+结案”的小批次报价。试谈价建议800至1500元，或合格内容每条40至80元并约定最小服务费。这些是定价测试假设，不是行业已核实价目表；不要为拿单承诺未知的播放量。

如果只允许音乐效果分佣，且没有服务费，按后文音乐模型决定是否值得执行。若上游只给一个无法归因的公共任务链接，不能把它称作你的可抽佣订单。

## 05 官方准入成本：不是所有“入驻”都一样

| 身份 | 公开条件/门槛 | 对起步的意义 |
| --- | --- | --- |
| 星图客户 | 企业、对公、品牌及充值等 | 不是个人无资质免费发单入口 |
| 星图代理商 | 独立法人、注册资本至少100万元等；学习、答辩、10万元保证金 | 有订单和团队后再评估 |
| 星图任务服务商 | 公示办法列5万元合规保证金 | 不是几百元就能直接取得全部权限 |
| 效果招募服务商 | 说明写邀请制，暂不开放外部入驻 | 注册账号不等于得到任务 |
| 星广联投服务商 | 相应入驻后联系渠道咨询 | 业务能力、具体等级和任务安排另核实 |
| 第三方音乐联盟 | 已查到功能线索，细则未公开完整 | 必须确认准入、分佣、退出与实际回款 |

代理商公开须知的100万元是注册资本要求，10万元是保证金，不能误写成“必须先拿出110万元现金”。任务服务商5万元依据仍公开的2023年办法，平台保留调整权，实际签约时以新通知及协议核查。[S06][S07]

这里列的是不同制度的门槛，不能把代理、MCN、撮合服务商、任务服务商的条件互换。也不能替你承诺“先交钱一定能拿到官方任务”。

你目前最合适的研究方向是第三方的真实渠道合作，以及已有机构经允许的执行合作。先验证这两条，再决定要不要成立或升级主体、缴保证金和建团队。
