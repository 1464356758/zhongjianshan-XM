## 模板F：单任务执行协议要点
甲方：[委托及付款主体]
乙方：[你的真实签约主体]
附件：[任务ID与冻结规则、版权/营销授权、交付与报价清单]

1. 角色与权限：甲方保证其有权安排本任务及本外部执行范围；平台额外批准要求单独满足。乙方不冒充平台服务商，不以借号方式履约。
2. 工作范围：候选筛选[数量及标准]、确认[数量与标准]、内容检查[次数]、进度管理[期限]、结案[格式]。筛选失败、未被正式下单和内容交付应分别约定验收。
3. 服务报酬：按[固定费/合格交付费/经允许的预算比例]。写明含税、计佣基数、封顶、最低服务费和是否含其他成本。达人应付款和平台费用另列。
4. 验收与修改：以冻结任务要求为准；明确[次数与期限]。新增要求需重新确认价格和时间，不能无上限返工。
5. 付款：从[验收/公示/发票收到等]起算[具体天数]；按平台要求或经允许的阶段收款方式执行。平台订单本身按其规则结算。
6. 授权：音乐、画面、肖像和素材使用范围；原视频投流、二创和跨平台使用分别确认。
7. 异常：按真实原因处理逾期、取消、平台拒审、无效流量、删稿和拒付。无过错方已成立的报酬不能自动归零。
8. 数据与保密：只用必要资料，限定接收人和访问权限；不得发布到公开仓库或用于无关营销。
9. 引入与重复采购：仅保护已记录的特定任务/对象，合理约定期限和报酬；不得虚构独家管理权。已有客户关系排除在外。
10. 退出和争议：在途任务、已产生应付与已确认服务报酬先结清；争议按合同约定渠道解决，不以骚扰、曝光个人资料方式追款。

这是谈判条款清单，待填写主体、附件、数额及争议方式后再按实际平台和业务确认。它不替代任何平台审批。

## 模板G：单笔结算表
| 项目 | 记录要求 |
| --- | --- |
| task_id / rule_version | 固定，不因后续改价覆盖历史 |
| creator_id / video_id | 指向实际投稿与执行账号 |
| original_indicator | 原始展示指标，仅作参考 |
| accepted_indicator | 最终认可指标及来源 |
| gross_task_reward | 任务规则认可金额 |
| platform_deductions | 各项扣费与扣除依据 |
| tax_withholding | 实际代扣或应缴记录，不能用估计当实付 |
| creator_payable | 按合同及任务形成的达人应收 |
| your_fee_base / rate | 你的合法服务报酬口径 |
| your_receivable | 你应收的服务报酬，与预算分开 |
| amount_received / date | 实际回款金额和日期 |
| delivery_cost | 每个提交的沟通、审核和返工成本 |
| issue / resolution | 差异、拒付与处理证据 |
| retention_until | 视频应公开保留的日期 |
| evidence_pointer | 访问受控证据位置，不存公开个人资料 |
